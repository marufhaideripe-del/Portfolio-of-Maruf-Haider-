Changeover examples: frame→frame 29 → 14.5 min; bed→frame 127 → 53 min.

Key findings

  • Changeover done by one operator alone, no supervisor or maintenance check
  • Same style ran at 500 rpm on one machine and 570 on another: settings set by trial
  • Applique delay and placement = 75% of idle time in Study 3
  • 4–7 min gaps between batches; lay and fusing done in sequence with stitching

15-point action plan (summary)

  • Min. 2 people + checklist on every changeover; stage frames, bobbins and applique before stop
  • Setup sheet per style (rpm, needle, tension) fixed at development before bulk
  • Group machines by stitch count; pre-wound bobbins; thread-break log
  • Re-measure after 4 weeks (projection uses a 50% realisation assumption)

Where it runs

  • Cutting floor: production and quality, Y/D section
  • Printing floor: input and QC areas
  • Embroidery: input area and QC table
  • Cutting input area and sewing input delivery

Hardware

114 tablets (Honor Pad X9) + 150 QR scanners (Winson M8 2D): BDT 45.55 L, part of the total investment.

What it delivers
